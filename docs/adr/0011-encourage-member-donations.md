# Encourage Members to donate

The network should encourage Members to donate toward its continued operation, including the AI
credits that power People Search and Resource indexing. Authenticated Members and Admins see a
site-wide footer prompt that opens a personal donation dialog; sign-in, invite, and onboarding flows
do not show it. Donations remain optional and happen outside the network using display-only Revolut
details that Members can copy, so donating is never a condition of membership or access.
